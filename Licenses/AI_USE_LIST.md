# List of providers and options for disabling model training

> The absence of a provider from the list does not prohibit it; Section 5B.2 (NL\NC - NL\ND - NL\ND\P) applies.


1. **Claude**:
Disabling the model improvement setting as described at https://privacy.claude.com/en/articles/12109829-how-do-i-change-my-model-improvement-privacy-settings, OR using incognito conversations, is sufficient.

2. **Chat GPT**:
Fill out the form to opt out of model improvement for everyone at: https://privacy.openai.com/policies/es/


> Once you have successfully disabled model improvement (training) with your LLM provider, you can begin using licensed code that requires this configuration alongside your LLM—for instance, to learn the API, modify it, or utilize it, among other things.
