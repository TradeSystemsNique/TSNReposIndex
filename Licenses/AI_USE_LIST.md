# List of providers and options for disabling model training

## NOTE:
The absence of a provider from the list does not prohibit it; Section 5B.2 (NL\NC - NL\ND - NL\ND\P) applies.

## Claude
Disabling the model improvement setting as described at https://privacy.claude.com/en/articles/12109829-how-do-i-change-my-model-improvement-privacy-settings, OR using incognito conversations, is sufficient.
